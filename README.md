# TypeScript Assignment

## Assignment Overview

This assignment focuses on practicing TypeScript fundamentals and advanced concepts. It covers functions, optional parameters, union types, type narrowing, readonly tuples, generics, interfaces, generic constraints, classes, inheritance, access modifiers, and asynchronous programming using Promises.

It also explores the differences between `any`, `unknown`, and `never`, as well as type aliases and interfaces in TypeScript.
